# Task 5 - Heart Disease Classification Using Tree-Based Models

#Objective

Build and evaluate Decision Tree and Random Forest classification models to predict the presence of heart disease using machine learning techniques.

#Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

#Steps Performed

* Loaded the Heart Disease Dataset
* Performed data exploration and understanding
* Prepared features and target labels
* Divided the dataset into training and testing sets
* Implemented a Decision Tree Classifier
* Visualized the trained Decision Tree
* Reduced overfitting using depth restriction
* Built a Random Forest Classifier
* Compared model accuracies
* Evaluated performance using:

  * Accuracy Score
  * Confusion Matrix
  * Classification Report
  * Cross-Validation Score
* Examined Feature Importance rankings
* Visualized important features and extracted meaningful insights

## Dataset

Heart Disease Dataset From Kaggle
